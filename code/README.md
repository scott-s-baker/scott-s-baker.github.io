# Code Samples

Selected code and systems — proof that you operate at the technical level, not just above it. This is a differentiator for a marketing executive, so choose a few clean, well-documented examples.

**How to use this folder:**
- Add each project as a subfolder with its own short README (what it does, why, tech used), or link out to a separate GitHub repo from a homepage card.
- Keep secrets/keys out of any code you publish.
- To feature on the homepage, edit the cards in the `#code` section of `../index.html`.

**Ideas that fit your background:**
- A **market-intelligence / signal-monitoring** script (ingests competitor, analyst, or press signals).
- An **AI content-generation workflow** (prompt/agent pipeline that produces briefs, one-pagers, battlecards).
- A **document-automation** tool (e.g. templated résumé/collateral generation).
- A small nod to your engineering roots (a clean algorithm or systems snippet).

> Tip: 3–4 polished, documented samples beat a dozen rough ones. README quality signals as much as the code.
